
## Controles

| Acción | Tecla |
|---|---|
| Moverse | `A` / `D` o flechas ← → |
| Saltar | `Espacio` |
| Doble salto | `Espacio` (en el aire) |
| Dash | `Shift` |
| Atacar | `K` o click izquierdo |
| Interactuar | `E` |

Shortcuts de testing: `H` activa/desactiva el doble salto y `J` el dash (el estado se imprime en la consola de Godot).
